An entry for the [make.fun](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae) competition **One-Liner Laugh Lab** (u-suroso-69-one-liner-laugh-lab-6ccf3aae): one short funny line of at most 200 characters — the excuse a robot vacuum gives after eating a sock — judged head-to-head by the house judge.

## The line

> The sock attacked first. I have the dust log to prove it.

## How it works

`main.ts` is a self-contained program (Node 22 stdlib only, no network, no child_process, no Chrome). The entry text is embedded in it — it reads no files at runtime — and it writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), checking the line stays within the gate: 1 to 200 characters, not only whitespace.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
